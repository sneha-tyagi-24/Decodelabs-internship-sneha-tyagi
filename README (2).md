# Project 3 — Phishing Awareness Analysis
**DecodeLabs Cybersecurity Training | Batch 2026**

## Overview
This project is the detection-phase milestone of the DecodeLabs Cybersecurity Training track. It focuses on **threat identification** rather than technical implementation: analyzing sample emails/messages to spot phishing attempts, listing the red flags that give them away, and explaining why each message is unsafe.

## Project Goal
Analyze sample emails or messages to identify phishing attempts by:
- Identifying suspicious links or keywords
- Listing red flags found in phishing messages
- Explaining why each message is unsafe

## Deliverable Summary
The main `.docx` file contains:
1. **Triage Checklist** — a practical, non-expert checklist covering sender/domain verification, link inspection, urgency/authority triggers, attachment risk, and requests for sensitive info.
2. **Decision Tree** — a simple classification table that sorts any incoming message into **Safe → Close**, **Suspicious → Warn User**, or **Malicious → Block & Escalate**.
3. **Worked Examples** — three realistic sample messages (mass phishing, spear phishing/BEC, and a suspicious internal-style notice), each annotated with the specific red flags found and a final classification.

## Key Skills Demonstrated
- Threat analysis
- Awareness of common cyber attack patterns (phishing, spear phishing, whaling, smishing, vishing, quishing)
- Security-first decision-making under a non-technical, real-world lens

## Notes
- No code was required for this project — it is a pure analysis and documentation exercise.
- The checklist and decision tree are designed to be usable by a non-technical employee, not just a security professional.
